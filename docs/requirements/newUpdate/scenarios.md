# Lecture Buddy — User Scenarios

User Scenarios ของ Lecture Buddy อธิบายสถานการณ์การใช้งานของผู้ใช้แต่ละ Persona ตั้งแต่ปัญหาที่พบ การดำเนินการภายในระบบ ไปจนถึงผลลัพธ์ที่ผู้ใช้คาดหวัง

---

## Scenario 1: จัดระเบียบ Lecture ที่กระจัดกระจาย

**Persona:** มินท์ — *The Note Collector*

**Objective:** รวบรวมเอกสารและโน้ตของวิชา Software Engineering ให้เป็นหมวดหมู่เดียวกัน

### Scenario

มินท์เพิ่งกลับจากเรียน Software Engineering และพบว่าเธอมีทั้งไฟล์ PowerPoint จากอาจารย์ รูปภาพกระดาน และโน้ตที่จดเองอยู่หลายแห่ง เธอเปิด Lecture Buddy แล้วเลือกวิชา Software Engineering จากนั้นสร้างบทเรียน **“Chapter 3: Scrum”** และอัปโหลดไฟล์ Lecture เข้าไป

ระบบให้เธอยืนยันว่าไฟล์นี้อยู่ในวิชาและบทเรียนใด ก่อนจัดเก็บให้อัตโนมัติ หลังจากนั้นเธอเพิ่มโน้ตที่จดเองและปักหมุดประเด็นที่อาจารย์เน้นไว้

### Action Sequence

**เปิด Dashboard** → **เลือกวิชา** → **เลือกบทเรียน** → **Upload ไฟล์** → **เพิ่มโน้ต** → **ปักหมุดเนื้อหาสำคัญ**

### Pain Point

เอกสารและโน้ตเดิมกระจัดกระจายอยู่หลายแห่ง ทำให้เสียเวลาในการรวบรวมและจัดหมวดหมู่

### Expected Outcome

เอกสารและโน้ตทั้งหมดของบทเรียนถูกจัดเก็บไว้ในที่เดียว สามารถค้นหาและกลับมาใช้งานได้ง่าย

---

## Scenario 2: เปลี่ยน Lecture ยาวให้เป็นสรุป

**Persona:** มินท์ — *The Note Collector*

**Objective:** ทำความเข้าใจ Lecture จำนวนมากภายในเวลาจำกัด

### Scenario

คืนก่อนสอบ มินท์เปิด Lecture Buddy และเข้าไปที่ **Chapter 3** เธอพบว่าไฟล์ Lecture มีความยาวกว่า 60 หน้า จึงเลือกใช้ฟังก์ชัน **“AI Summary”** แทนการอ่านเอกสารทั้งหมด

ระบบสร้างสรุปพร้อม **Key Points** และคำศัพท์สำคัญให้เธอ มินท์อ่านสรุปและพบว่าบางหัวข้อยังไม่เข้าใจ จึงเลือกหัวข้อนั้นและกด **“Explain Simply”** เพื่อให้ AI อธิบายเนื้อหาในรูปแบบที่เข้าใจง่ายขึ้น

### Action Sequence

**เปิดบทเรียน** → **เลือกเอกสาร** → **กด AI Summary** → **อ่าน Key Points** → **เลือกหัวข้อที่ไม่เข้าใจ** → **กด Explain Simply**

### Pain Point

Lecture มีเนื้อหาจำนวนมากและไม่รู้ว่าประเด็นใดสำคัญ ทำให้ใช้เวลานานในการอ่านและทำความเข้าใจ

### Expected Outcome

สามารถเข้าใจภาพรวมและประเด็นสำคัญของบทเรียนได้รวดเร็วขึ้น โดยไม่จำเป็นต้องอ่านเอกสารทั้งหมดตั้งแต่ต้น

## Scenario 3: ทดสอบความเข้าใจก่อนสอบ

**Persona:** เจมส์ — *The AI Learner*

**Objective:** ตรวจสอบว่าตัวเองเข้าใจเนื้อหาจริงหรือเพียงแค่จำจาก Summary

### Scenario

หลังจากเจมส์อ่านสรุปเรื่อง **Database Normalization** แล้ว เขาต้องการทดสอบความเข้าใจของตัวเอง จึงกด **“สร้างคำถามทบทวน”** และเลือกระดับความยากปานกลาง จำนวน 10 ข้อ

Lecture Buddy สร้างคำถามจากเอกสารที่เจมส์เพิ่มไว้ เขาตอบคำถามทีละข้อ และระบบแสดงเฉลยพร้อมคำอธิบาย หลังทำแบบทดสอบเสร็จ ระบบแสดงหัวข้อที่เจมส์ตอบผิดบ่อยจำนวน 3 เรื่อง และแนะนำให้กลับไปทบทวนหัวข้อเหล่านั้น

### Action Sequence

**เปิด Summary** → **กด Generate Questions** → **เลือกจำนวน/ระดับความยาก** → **ทำ Quiz** → **ดูเฉลย** → **ดูหัวข้อที่ควรทบทวน**

### Pain Point

ไม่สามารถประเมินได้อย่างชัดเจนว่าตัวเองเข้าใจเนื้อหาจริงหรือเพียงแค่จำจาก Summary

### Expected Outcome

รู้จุดอ่อนของตัวเอง สามารถระบุหัวข้อที่ยังไม่เข้าใจ และกลับไปทบทวนเฉพาะส่วนที่จำเป็นได้

## Scenario 4: ไม่รู้ว่าจะเริ่มอ่านอะไรก่อนสอบ

**Persona:** แพรว — *The Last-Minute Reviewer*

**Objective:** วางแผนการทบทวนก่อนสอบโดยมีเวลาจำกัด

### Scenario

แพรวมีเวลาเพียงสองวันก่อนสอบ แต่มี Lecture ทั้งหมด 8 บท เธอเปิดหน้า **Review** ของ Lecture Buddy และพบ Checklist ของแต่ละบท

ระบบแสดงว่าเธออ่านไปแล้ว 3 บท แต่ยังไม่ได้ทำ Quiz อีก 4 บท นอกจากนี้ AI ยังแนะนำว่า **Chapter 5** เป็นหัวข้อที่ควรให้ความสำคัญ เนื่องจากมีเนื้อหาที่เชื่อมโยงกับหลายบท

แพรวจึงเลือก **“เริ่มทบทวน”** และทำตามลำดับที่ระบบแนะนำ

### Action Sequence

**เปิด Review** → **ดู Progress** → **ดู Checklist** → **ดู AI Recommendation** → **เลือกบทเรียน** → **เริ่มทบทวน**

### Pain Point

มีเนื้อหาจำนวนมากและมีเวลาจำกัด แต่ไม่รู้ว่าควรเริ่มอ่านจากบทใดหรือควรให้ความสำคัญกับหัวข้อใดก่อน

### Expected Outcome

มีลำดับการทบทวนที่ชัดเจน เห็นความคืบหน้าของตนเอง และรู้ว่ามีเนื้อหาหรือกิจกรรมใดที่ยังต้องทำ

## Scenario Overview

| Scenario              | Persona | Main Problem                     | Key Feature                | Expected Outcome         |
| --------------------- | ------- | -------------------------------- | -------------------------- | ------------------------ |
| 1. จัดระเบียบ Lecture | มินท์   | เอกสารกระจัดกระจาย               | Lecture Management         | เอกสารอยู่ในที่เดียว     |
| 2. สรุป Lecture       | มินท์   | Lecture ยาวและจับประเด็นยาก      | AI Summary                 | เข้าใจเนื้อหาเร็วขึ้น    |
| 3. ทดสอบความเข้าใจ    | เจมส์   | ไม่รู้ว่าตัวเองเข้าใจจริงหรือไม่ | AI Quiz                    | รู้จุดอ่อนของตัวเอง      |
| 4. วางแผนก่อนสอบ      | แพรว    | ไม่รู้ว่าจะเริ่มอ่านอะไร         | Review & AI Recommendation | มีลำดับการทบทวนที่ชัดเจน |

## Common User Journey

จากทั้ง 4 Scenarios สามารถมองเห็น User Journey หลักของ Lecture Buddy ได้ดังนี้:

**รวบรวม Lecture**
↓
**จัดหมวดหมู่ตามวิชาและบทเรียน**
↓
**อ่าน / สรุปด้วย AI**
↓
**ทำความเข้าใจเนื้อหา**
↓
**สร้าง Quiz เพื่อทดสอบตัวเอง**
↓
**วิเคราะห์จุดอ่อน**
↓
**วางแผนการทบทวน**
↓
**ติดตาม Progress ก่อนสอบ**

> **Lecture Buddy ช่วยให้นักศึกษาจัดการวงจรการเรียนตั้งแต่การรวบรวม Lecture ไปจนถึงการทบทวนและประเมินความพร้อมก่อนสอบในระบบเดียว**
