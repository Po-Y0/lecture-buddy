# Lecture Buddy — User Stories

User Stories ของ Lecture Buddy ถูกจัดทำขึ้นจากปัญหาและความต้องการของผู้ใช้จาก Persona และ User Scenarios โดยแบ่งความต้องการหลักออกเป็น 3 ด้าน ได้แก่ **Course & Note Management, AI Learning และ Review & Progress**

---

## 1. Course & Note Management

ฟังก์ชันสำหรับจัดการรายวิชา เอกสาร และโน้ต เพื่อช่วยให้นักศึกษารวบรวมเนื้อหาการเรียนไว้ในที่เดียวและค้นหาได้ง่าย

### US-01 — จัดการรายวิชา

> **As a student, I want to create and manage my courses so that I can organize my learning materials by subject.**

**Purpose:** ให้นักศึกษาสามารถสร้าง แก้ไข และจัดการรายวิชา เพื่อแบ่งเอกสารและเนื้อหาตามวิชา

---

### US-02 — สร้างโน้ต

> **As a student, I want to create notes under a specific course and lesson so that I can keep my class notes organized.**

**Purpose:** ให้นักศึกษาสามารถสร้างโน้ตภายใต้รายวิชาและบทเรียนที่กำหนด เพื่อจัดเก็บโน้ตอย่างเป็นระบบ

---

### US-03 — Upload เอกสาร

> **As a student, I want to upload learning documents to a course so that I can keep my study materials in one place.**

**Purpose:** ให้นักศึกษาสามารถอัปโหลด Lecture และเอกสารการเรียนเข้าสู่รายวิชา เพื่อรวบรวมเอกสารไว้ในระบบเดียว

---

### US-04 — ค้นหา

> **As a student, I want to search my notes and documents by keyword so that I can quickly find the information I need.**

**Purpose:** ให้นักศึกษาสามารถค้นหาโน้ตและเอกสารด้วย Keyword เพื่อเข้าถึงข้อมูลที่ต้องการได้อย่างรวดเร็ว

---

### US-05 — ปักหมุด

> **As a student, I want to pin important notes so that I can quickly access important information before an exam.**

**Purpose:** ให้นักศึกษาสามารถปักหมุดโน้ตหรือเนื้อหาที่สำคัญ เพื่อกลับมาเข้าถึงได้ง่ายในช่วงทบทวนก่อนสอบ

---

## 2. AI Learning

ฟังก์ชัน AI สำหรับช่วยนักศึกษาทำความเข้าใจ Lecture ลดเวลาในการอ่าน และสร้างรูปแบบการเรียนรู้จากเอกสารของตนเอง

### US-06 — สรุป

> **As a student, I want AI to summarize my notes and documents so that I can understand long content more quickly.**

**Purpose:** ให้ AI สรุปเนื้อหาจากโน้ตและเอกสาร เพื่อช่วยให้นักศึกษาเข้าใจเนื้อหาจำนวนมากได้รวดเร็วขึ้น

---

### US-07 — อธิบายง่าย

> **As a student, I want AI to explain difficult concepts in simple language so that I can understand lessons that I find difficult.**

**Purpose:** ให้ AI อธิบายแนวคิดหรือเนื้อหาที่ยากด้วยภาษาที่เข้าใจง่าย เพื่อช่วยลดความซับซ้อนของบทเรียน

---

### US-08 — สร้างคำถาม

> **As a student, I want AI to generate review questions from my learning materials so that I can test my understanding.**

**Purpose:** ให้ AI สร้างคำถามทบทวนจาก Lecture และเอกสารที่นักศึกษาเพิ่มเข้าสู่ระบบ เพื่อใช้สำหรับทดสอบความเข้าใจ

---

### US-09 — Quiz

> **As a student, I want to answer AI-generated quizzes and see explanations for incorrect answers so that I can learn from my mistakes.**

**Purpose:** ให้นักศึกษาสามารถทำ Quiz ที่สร้างโดย AI และดูคำอธิบายของข้อที่ตอบผิด เพื่อเรียนรู้จากข้อผิดพลาดของตนเอง

---

### US-10 — แนะนำหัวข้อ

> **As a student, I want AI to recommend related topics that I should study so that I know what to learn next.**

**Purpose:** ให้ AI แนะนำหัวข้อที่เกี่ยวข้องและควรศึกษาเพิ่มเติม เพื่อช่วยให้นักศึกษารู้ว่าควรเรียนรู้เรื่องใดต่อไป

---

## 3. Review & Progress

ฟังก์ชันสำหรับช่วยนักศึกษาวางแผน ติดตาม และประเมินความคืบหน้าในการทบทวนบทเรียนก่อนสอบ

### US-11 — Review Checklist

> **As a student, I want a review checklist for each lesson so that I can track what I have already studied.**

**Purpose:** ให้นักศึกษามี Checklist สำหรับแต่ละบทเรียน เพื่อบันทึกและติดตามว่าทบทวนเนื้อหาใดไปแล้วบ้าง

---

### US-12 — Progress

> **As a student, I want to see my review progress so that I know how prepared I am for an exam.**

**Purpose:** ให้นักศึกษาสามารถดูความคืบหน้าในการทบทวน เพื่อประเมินระดับความพร้อมก่อนสอบ

---

### US-13 — AI Study Recommendation

> **As a student, I want Lecture Buddy to recommend what I should review next so that I can spend my limited study time effectively.**

**Purpose:** ให้ Lecture Buddy วิเคราะห์ข้อมูลการเรียนและแนะนำหัวข้อที่ควรทบทวนต่อไป เพื่อให้นักศึกษาใช้เวลาที่มีอย่างจำกัดได้อย่างมีประสิทธิภาพ

## User Story Coverage

User Stories ทั้ง 13 รายการครอบคลุม User Journey หลักของ Lecture Buddy ตั้งแต่การจัดเก็บข้อมูล ไปจนถึงการเรียนรู้และการเตรียมสอบ

**Course & Note Management**
→ จัดการวิชา → เพิ่มโน้ต → Upload Lecture → ค้นหา → ปักหมุด

**AI Learning**
→ สรุปเนื้อหา → อธิบายเรื่องยาก → สร้างคำถาม → ทำ Quiz → แนะนำหัวข้อ

**Review & Progress**
→ สร้าง Checklist → ติดตาม Progress → รับคำแนะนำในการทบทวน

> **เป้าหมายของ Lecture Buddy คือช่วยให้นักศึกษาสามารถจัดการ Lecture เรียนรู้ด้วย AI และวางแผนการทบทวนก่อนสอบได้ภายในระบบเดียว**
