# Definition of Done — Lecture Buddy

A User Story is considered **Done** when all of the following conditions are met:

* [ ] ฟังก์ชันสามารถทำงานได้ตาม Acceptance Criteria ของ Issue ครบทุกข้อ
* [ ] มีการทดสอบฟังก์ชันหลักและแก้ไข Bug ที่พบซึ่งกระทบต่อการใช้งาน
* [ ] UI ของฟีเจอร์สามารถใช้งานได้จริงและสอดคล้องกับการออกแบบของทีม
* [ ] โค้ดได้รับการตรวจสอบจากสมาชิกทีมอย่างน้อย 1 คน
* [ ] มี Pull Request สำหรับการเปลี่ยนแปลงและผ่าน Code Review ก่อน Merge
* [ ] ไม่มี Conflict หรือ Error ที่กระทบต่อฟังก์ชันหลักหลัง Merge
* [ ] Issue และ Project Board ถูกอัปเดตสถานะให้ตรงกับความคืบหน้าจริง
* [ ] สมาชิกทีมที่รับผิดชอบสามารถอธิบายวิธีการทำงานของฟีเจอร์ได้
